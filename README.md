## Come contribuire

Ogni membro lavora **solo nella propria cartella**. Quando un documento è pronto e approvato dal gruppo, va spostato in `1_Doc. Conclusi/`.

### Workflow base

```bash
# Prima di iniziare a lavorare: aggiorna
git pull

# Dopo aver modificato o aggiunto file
git add Progettazione/<TuaCognome>/
git commit -m "descrizione breve di cosa hai aggiunto/modificato"
git push
```

### Regole

- Non modificare i file nelle cartelle degli altri
- Non modificare `1_Doc. Conclusi/` senza accordo del gruppo
- Commit frequenti, messaggi in italiano sono ok
